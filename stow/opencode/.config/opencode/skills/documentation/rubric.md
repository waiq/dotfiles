# Documentation Quality Rubric (0-100)

## Scoring

### 1) Purpose Fit (20)

- 0-5: purpose unclear or mixed
- 6-12: partially aligned with one doc type
- 13-20: clear single Diataxis fit and outcome

### 2) Readability and Scanability (20)

- 0-5: dense prose, weak headings
- 6-12: somewhat scannable, uneven structure
- 13-20: clean hierarchy, concise sections, easy scanning

### 3) Accuracy and Actionability (20)

- 0-5: vague or hard to execute
- 6-12: mostly usable with gaps
- 13-20: concrete steps/examples; reader can execute confidently

### 4) Markdown and Style Compliance (20)

- 0-5: multiple style violations
- 6-12: minor inconsistencies
- 13-20: strong compliance with style baseline

### 5) Maintenance and Reusability (20)

- 0-5: no metadata/ownership signals
- 6-12: partial metadata and weak linking
- 13-20: complete metadata, links, and durable structure

## Rating Bands

- 90-100: Excellent (release-ready)
- 85-89: Good (ship with minor polish)
- 70-84: Fair (needs revision)
- <70: Rework required

## Reporting Format

```text
Checklist: PASS|FAIL
Rubric score: NN/100
Band: <rating>
Top improvements:
1) ...
2) ...
3) ...
```
